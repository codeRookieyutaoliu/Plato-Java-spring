# plato-protocol 模块测试说明

## 测试策略

plato-protocol 模块的测试策略包含两个层次：

1. **基础测试**：不依赖 Protobuf 生成的类，测试基本的编解码和传输功能
2. **集成测试**：依赖 Protobuf 生成的类，测试更完整的功能

这种策略确保了即使在 Protobuf 类未生成的情况下，也能运行基本测试以验证核心功能的正确性。

## 测试类型

### 基础测试（不依赖 Protobuf）

* **BasicCodecTest**：测试 TCP 编解码基本功能
  - 数据包的序列化和反序列化
  - 消息编码和解码
  - 分片消息处理

* **BasicTransportTest**：测试传输层基本功能
  - 连接和断开
  - 消息发送和接收
  - 异步操作
  - 配置管理
  - 异常处理

### 集成测试（依赖 Protobuf）

* **ProtobufTest**：测试 Protobuf 消息的序列化和反序列化
  - 各种消息类型的编解码
  - 消息结构的完整性

* **IntegrationTest**：测试各组件的协作
  - 端到端消息流
  - 不同类型消息的处理
  - 大消息和分片处理

## 如何运行测试

### 前提条件

- 安装 Java 21 或更高版本
- 安装 Maven 3.6 或更高版本

### 方法一：使用脚本（推荐）

执行 `compile_and_test.bat` 脚本，它会自动执行以下步骤：

1. 编译代码并生成 Protobuf 类
2. 运行不依赖 Protobuf 的基本测试
3. 如果 Protobuf 类生成成功，运行依赖 Protobuf 的集成测试

```bash
cd Plato-Java-spring/plato-framework/plato-protocol
./compile_and_test.bat
```

### 方法二：手动运行

1. 编译代码并生成 Protobuf 类：

```bash
mvn clean compile
```

2. 运行全部测试：

```bash
mvn test
```

3. 只运行基本测试：

```bash
mvn test -Dtest=BasicCodecTest,BasicTransportTest
```

4. 只运行依赖 Protobuf 的测试：

```bash
mvn test -Dtest=ProtobufTest,IntegrationTest
```

## 测试覆盖范围

### codec 包

- DataPacket：数据包结构
- MessageEncoder/MessageDecoder：消息编解码
- TcpCodecHandler：TCP 编解码处理器
- TcpFrameDecoder：TCP 帧解码器

### transport 包

- Transport 接口：传输层抽象
- TransportConfig：传输配置
- TransportException：异常处理

### proto 文件

- message.proto：消息定义
- 生成的 Java 类：自动化测试验证

## 注意事项

1. 基础测试不依赖 Protobuf 生成的类，因此即使 Protobuf 编译失败也能运行
2. 集成测试依赖 Protobuf 生成的类，如果类未生成，测试会自动跳过
3. 在运行测试前，确保项目已正确编译
